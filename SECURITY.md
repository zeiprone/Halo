# Security Policy

## Supported versions

Security fixes are provided for the latest version on the repository’s default branch.

## Reporting a vulnerability

Please use GitHub’s **Report a vulnerability** feature in the repository’s Security tab. Do not open a public issue for a potential vulnerability.

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge reports as soon as practical and coordinate a fix and disclosure timeline with the reporter.
