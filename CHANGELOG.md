# Changelog

All notable changes to Halo are documented in this file. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Public repository documentation, contribution templates, CI, and release packaging.

## [0.3.0] - 2026-10-19

### Added

- Compact and expanded MacBook notch player with artwork, animated waveform, seeking, playback controls, lyrics toggle, and visual settings shortcut.
- Synchronized lyric overlays with editorial, focus, and fisheye presentation modes.
- Audio-reactive ambient lighting using in-memory Spotify audio analysis.
- Album-art palette extraction, multi-display overlays, and per-track lyric offsets.
